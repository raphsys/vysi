# 00 — Principes architecturaux figés

1. L'original binaire est la source ultime et reste préservé.
2. Le modèle natif est la vérité structurelle principale.
3. L'IR commune est une projection utile, jamais une substitution silencieuse.
4. Le rendu est une vue dérivée, versionnée et reproductible.
5. Les représentations sont reliées par des mappings explicites.
6. Les éléments inconnus sont conservés comme parties opaques.
7. Aucun contenu actif, formule, macro ou relation externe n'est exécuté.
8. Toute perte ou approximation est mesurée et rapportée.
9. Les contrats sont immuables, versionnés et hashés.
10. Le pipeline est piloté par capacités, non par extensions de fichiers.
