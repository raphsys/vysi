# 01 — DocumentEnvelope

`DocumentEnvelope` est le contrat racine. Il référence l'artefact original,
le format, le conteneur, le modèle natif, l'IR commune, les vues rendues,
les mappings, les ressources et les rapports de qualité/sécurité.

Aucune référence de rendu n'est obligatoire lorsque le rendu n'a pas été demandé.
