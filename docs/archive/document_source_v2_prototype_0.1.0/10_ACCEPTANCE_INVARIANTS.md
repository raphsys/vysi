# 10 — Invariants d'acceptation

- original préservé et hashé ;
- format déterminé par contenu ;
- chaque partie de conteneur inventoriée ;
- au moins une racine native ou une erreur bloquante ;
- chaque unité IR référence une unité native ;
- aucune perte silencieuse ;
- aucun contenu actif exécuté ;
- aucune ressource externe téléchargée ;
- couverture et préservation présentes ;
- commit atomique uniquement après validation.
