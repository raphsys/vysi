# plain_text.v2

- octets/encodage/BOM ;
- séparateurs de lignes ;
- lignes et plages d’octets ;
- tabulations et contrôles Unicode ;

## Règles

- aucune pagination native ;
- Markdown/CSV/code comme projections secondaires ;

Toute fonction rencontrée mais non modélisée reste opaque et apparaît dans les rapports.
