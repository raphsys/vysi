# wordprocessing.v2

## Structure minimale

- sections ;
- paragraphes/runs ;
- tableaux ;
- styles/numérotation/thèmes ;
- headers/footers ;
- notes/commentaires/révisions ;
- champs/content controls ;
- objets incorporés ;

## Règles

- pagination dérivée du moteur ;
- couches contenu/révision/annotation/champ séparées ;

Toute fonction rencontrée mais non modélisée reste opaque et apparaît dans les rapports.
