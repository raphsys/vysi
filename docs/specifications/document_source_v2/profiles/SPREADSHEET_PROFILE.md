# spreadsheet.v2

## Structure minimale

- classeur/feuilles ;
- cellules/plages ;
- formules et valeurs cache ;
- styles et formats numériques ;
- noms définis ;
- validations/filtres/tables ;
- graphiques/images/commentaires ;
- zones d’impression ;

## Règles

- aucun recalcul implicite ;
- feuille distincte de page d’impression ;

Toute fonction rencontrée mais non modélisée reste opaque et apparaît dans les rapports.
