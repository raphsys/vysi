# 24 — Terminologie normative

- **artefact** : séquence d'octets acquise ;
- **bundle** : ensemble ordonné d'artefacts d'une demande ;
- **conteneur** : structure physique regroupant parties ou streams ;
- **modèle natif** : structure fidèle au format source ;
- **IR technique** : projection commune sans sémantique éditoriale ;
- **vue rendue** : résultat visuel d'un moteur et environnement ;
- **surface** : unité visuelle d'une vue ;
- **asset** : fichier dérivé matérialisé ;
- **mapping** : correspondance prouvée entre représentations ;
- **opaque** : préservé mais non interprété ;
- **couverture** : part des fonctions rencontrées effectivement traitées ;
- **préservation** : pertes et transformations entre couches ;
- **fidélité** : qualité mesurée selon un axe ;
- **round-trip** : capacité à réécrire sans pertes déclarées ;
- **package** : sortie persistée, portable et vérifiable.
