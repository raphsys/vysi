# 08 — TechnicalDocumentIR

`TechnicalDocumentIR` est une projection technique interopérable. Il contient uniquement des faits
observables ou explicitement dérivés : texte, objets, tableaux, cellules, formules, ressources, adresses,
styles et hiérarchies techniques.

Il n'attribue pas les concepts « titre », « chapitre », « auteur », « légende », « paragraphe de corps » ou
« unité de traduction ». Ces notions appartiennent à l'analyse documentaire.

Chaque unité IR référence au moins une unité native ou explique son origine synthétique. L'IR ne peut pas
être utilisée pour réécrire le format source sans consulter le modèle natif et le rapport de préservation.
