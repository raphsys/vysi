# 21 — Stratégie de tests

Niveaux obligatoires : schéma, modèle Python, invariant, unité, intégration, acceptation, sécurité, fuzz,
stress, concurrence, reprise, cancellation, déterminisme et compatibilité.

Chaque contrat possède exemples valides et invalides. Chaque code d'erreur bloquant possède un test.
Chaque profil possède corpus synthétique, public et réel. Les tests de rendu comparent structure, mappings
et assets sans imposer une identité pixel parfaite entre moteurs différents.

La matrice normative se trouve dans `matrices/TEST_MATRIX.md`.
