# 11 — Sécurité et budgets

Toute source est hostile par défaut. Les politiques couvrent : réseau, macros, JavaScript, DDE, ActiveX,
modèles distants, connexions de données, liens externes, formules, champs automatiques, pièces jointes,
objets incorporés, signatures, chiffrement et extraction récursive.

Budgets obligatoires : octets source, items du bundle, parties, streams, décompression, ratio, profondeur,
XML nodes/depth/text, pages/slides/feuilles/cellules/formules, ressources, pixels, mémoire, CPU, durée,
stockage temporaire, sortie et profondeur de documents enfants.

Une limite dure arrête la portée concernée. Une limite souple produit un finding et suit `StrictnessPolicy`.
Les observations de limite sont persistées avec valeur configurée, observée, portée et action.
